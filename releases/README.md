# Development installers

[Phosrack 0.3.1](v0.3.1/README.md) adds direct Spotify connection using the project's
public application ID. It provides Windows x64 installer/portable packages, a
Fedora 45 RPM, a Debian 13 DEB and a KDE-runtime Flatpak after their builds complete.
The version directory records validation and SHA256 checksums with each delivery.

[Phosrack 0.3.0](v0.3.0/README.md) remains available with its original build provenance.

These are unsigned development builds. Follow [Getting started](../GETTING_STARTED.md)
and the [packaging notes](../docs/packaging.md) for installation. The
[0.3.1 validation notes](../docs/validation-0.3.1.md) distinguish completed checks from
manual audio-hardware and Spotify account checks that remain open.

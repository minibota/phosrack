# Development installers

Versioned installable artifacts belong in releases/v0.3.0/. Native Linux packages
are built in their target distributions; Windows packages are generated by the
native MSVC workflow. Each delivery includes checksums and validation notes.

These are development builds. Do not label a package as tested on Windows before
the native workflow and runtime checks have completed. Follow GETTING_STARTED.md
and docs/packaging.md when installing unsigned development packages.

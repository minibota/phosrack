# Development installers

[Phosrack 0.3.3](v0.3.3/README.md) reduces Spotify API requests, respects persistent
cooldowns, restores saved sessions and adds a clearer browser sign-in experience.
Spotify uses ambient visuals; audio-reactive tools are separate for non-Spotify audio.
The release provides Windows x64 installer/portable packages, a Fedora 45 RPM,
a Debian 13 DEB and a KDE-runtime Flatpak.

The version directory contains download links, provenance and SHA256 checksums.
Large WebEngine bundles are attached to GitHub Releases rather than stored in Git.
[Phosrack 0.3.2](v0.3.2/README.md), [0.3.1](v0.3.1/README.md) and [0.3.0](v0.3.0/README.md) remain available
with their original build provenance.

These are unsigned development builds. Follow [Getting started](../GETTING_STARTED.md)
and the [packaging notes](../docs/packaging.md) for installation. The
[0.3.3 validation notes](../docs/validation-0.3.3.md) distinguish completed checks from
platform-specific audio and DRM checks that remain open.

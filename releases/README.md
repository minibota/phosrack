# Development installers

[Phosrack 0.3.0](v0.3.0/README.md) provides Windows x64 installer/portable packages,
a Fedora 45 RPM, a Debian 13 DEB and a KDE-runtime Flatpak. The version directory
contains their SHA256 checksums and links to the native build records.

These are unsigned development builds. Follow [Getting started](../GETTING_STARTED.md)
and the [packaging notes](../docs/packaging.md) for installation. The
[validation record](../docs/validation.md) states what was built and tested, including
manual audio-hardware checks that remain open.
